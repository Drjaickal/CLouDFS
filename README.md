# CloudFS

A Cloud-Based Distributed File Storage System.

## Objective

Build a distributed file storage platform
using multiple independent storage nodes.

## Core Features

- Distributed file storage
- File replication
- Fault tolerance
- Node health monitoring
- Load balancing
- Secure file access
- Cloud deployment

## Technology Stack

- Next.js
- Node.js
- TypeScript
- PostgreSQL
- Docker
- Google Cloud Platform
